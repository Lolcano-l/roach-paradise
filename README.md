# 蟑螂乐园 Roach Paradise

一个运行在 Windows 桌面上的像素风蟑螂生态模拟器。

## 功能

- 蟑螂在桌面自由活动，不影响普通鼠标操作
- 停留、转向、快速冲刺、贴边、聚集和避开鼠标
- 昼伏夜出与成虫自然死亡
- 卵鞘 → 阶段一 → 阶段二 → 成虫的完整生命周期
- 每个阶段都有独立的 16-bit 像素贴图与行走动画
- 像素杀虫剂贴图、喷洒动画和范围伤害
- 控制面板显示各阶段数量、行为状态并控制种群规模

## 下载与运行

在仓库的 `release` 文件夹下载 `RoachParadise.exe`，双击运行即可。

这是一个兼容 32/64 位 Windows 的桌面程序。若 SmartScreen 提示未知发布者，请先确认文件来自本仓库，再选择是否运行。

## 操作

- `F8`：开启或关闭杀虫剂模式
- `F9`：显示或隐藏控制面板
- 杀虫剂模式下点击：喷洒
- 杀虫剂模式下右键：退出喷洒模式
- 右击系统托盘图标：投放、暂停、重启或退出

## 从源码构建

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
```

构建结果位于 `release/RoachParadise.exe`。脚本使用 Windows 自带的 .NET Framework C# 编译器，不需要额外下载依赖。

## 项目结构

```text
assets/   像素动画素材
src/      C# / WPF 源码
release/  可直接运行的程序与说明
build.ps1 本地构建脚本
```

## 当前限制

- 仅支持 Windows
- 当前生态状态不会在退出后保存
- 程序尚未进行代码签名，因此 Windows 可能显示未知发布者提示
